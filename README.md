# 🍼 Малышок — Telegram бот для молодых родителей

## Структура проекта

```
baby-bot/
├── src/
│   ├── index.js        # Главный файл бота
│   ├── claude.js       # Генерация сообщений через Claude API
│   ├── database.js     # Работа с базой пользователей
│   ├── utils.js        # Утилиты (возраст, блоки знаний)
│   └── messages.js     # Тексты сообщений
├── knowledge-base/     # База знаний по возрастам (5 блоков + конституция)
├── data/               # База пользователей (создаётся автоматически)
├── .env.example        # Пример переменных окружения
└── package.json
```

## Установка и запуск

### 1. Установить зависимости
```bash
npm install
```

### 2. Создать .env файл
```bash
cp .env.example .env
```
Заполнить:
- `BOT_TOKEN` — получить у @BotFather в Telegram
- `ANTHROPIC_API_KEY` — получить на console.anthropic.com

### 3. Скопировать базу знаний
Положить все 5 блоков и CONSTITUTION.md в папку `knowledge-base/`

### 4. Запустить бота
```bash
npm start
```

## Деплой на Railway

1. Создать аккаунт на railway.app
2. Создать новый проект → Deploy from GitHub
3. Добавить переменные окружения в Settings → Variables
4. Бот запустится автоматически

## Подключение оплаты (ЮКасса)

1. Зарегистрироваться на yookassa.ru как самозанятый
2. Создать платёж через API ЮКассы
3. Заменить заглушку `pay_sub` в index.js на реальную ссылку
4. Настроить webhook для автоматической активации подписки после оплаты

## Лимиты и экономика

- Бесплатный период: 3 дня
- Подписка: 299 ₽/мес или 2 490 ₽/год  
- Лимит вопросов: 30/месяц
- Себестоимость API на пользователя: ~60 ₽/мес
- Маржа: ~240 ₽ с пользователя в месяц
